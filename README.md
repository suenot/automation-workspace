# automation-workspace

Git workspace of social-media content publishing automation projects (submodules).

| Submodule | Platform |
|---|---|
| facebook-automation | Facebook |
| instagram-automation | Instagram |
| metadata-automation | Metadata |
| pinterest-automation | Pinterest |
| threads-automation | Threads |
| tiktok-automation | TikTok |
| x-automation | X |
| youtube-automation | YouTube |

Clone: `git clone --recurse-submodules <url>`. Update all: `git submodule update --remote`.
